# Двадцать переходов для фоторамки и предпросмотра

В общем реестре `Effect.values` доступны `Soft Wipe`, `Light Sweep`, `Slice`,
`Luma Fade`, `Page Peel`, `Light Leak`, `Film Roll`, `Cross Zoom`, `Whip`,
`Glass`, `Clock Wipe`, `Split`, `Panel Wipe`, `Stretch`, `Star Wipe`,
`Film Dissolve`, `Frame`, `Louver`, `Mirror`, `Neon Wipe`.
Это самостоятельные реализации визуальных приёмов,
известных по видеоредакторам, включая Premiere Pro.

| Имя JSON/API | Русская подпись | Поведение |
| --- | --- | --- |
| `Soft Wipe` | Мягкое раскрытие | Следующее медиа открывается слева направо через широкую мягкую границу. |
| `Light Sweep` | Световой проход | Такое же раскрытие, дополненное тёплым световым бликом на границе. Блик плавно появляется и исчезает. |
| `Slice` | Сдвиг полос | Восемь горизонтальных полос исходящего кадра уезжают попеременно влево и вправо с задержкой сверху вниз. |
| `Luma Fade` | Растворение по яркости | Сначала исчезают светлые участки исходящего кадра, затем тёмные; граница яркости мягкая. |
| `Page Peel` | Загиб страницы | Верхний правый угол загибается к нижнему левому. Видны светлая бумажная обратная сторона, затенённый сгиб и тень листа. |
| `Light Leak` | Световая засветка | Кадры смешиваются под движущейся тёплой засветкой с ярким центром. |
| `Film Roll` | Прокрутка плёнки | Исходящий кадр уезжает вверх, входящий появляется снизу; вертикальное размытие и движущаяся перфорация создают вид киноплёнки. |
| `Cross Zoom` | Встречный зум | Исходящий кадр увеличивается, входящий уменьшается до обычного размера; в середине они смешиваются с размытием. |
| `Whip` | Резкая панорама | Быстрый сдвиг влево с горизонтальным размытием, наиболее сильным в середине перехода. |
| `Glass` | Стекло | Восемь вертикальных граней по-разному смещают и слегка увеличивают изображение при смене кадра; на границах видны блики. |
| `Clock Wipe` | Часовое раскрытие | Следующее медиа открывается сектором по часовой стрелке, начиная сверху от положения «12 часов». |
| `Split` | Раздвижение половин | Две половины исходящего кадра разъезжаются влево и вправо, открывая следующее медиа в центре. |
| `Panel Wipe` | Раскрытие панелями | Восемь горизонтальных полос открывают следующий кадр по очереди сверху вниз, попеременно слева и справа. Сами пиксели остаются на месте. |
| `Stretch` | Растяжение | Исходящий кадр растягивается по горизонтали, входящий сжимается до обычной ширины; кадры плавно смешиваются. Высота не меняется. |
| `Star Wipe` | Раскрытие звездой | Следующее медиа раскрывается из центра растущей пятиконечной звездой. |
| `Film Dissolve` | Кинематографическое растворение | Плавное смешивание в линейном цветовом пространстве с преобразованием sRGB до и после композиции. |
| `Frame` | Рамка | Следующее медиа раскрывается в растущей прямоугольной рамке со светлой окантовкой и тенью. |
| `Louver` | Поворотные жалюзи | Восемь вертикальных планок поворачиваются в 3D с задержкой слева направо, меняя исходящий кадр на входящий. Между повёрнутыми планками виден чёрный фон. |
| `Mirror` | Зеркало | Зеркальная копия правой части кадра временно раскрывается поверх левой; в середине изображение симметрично относительно центра. |
| `Neon Wipe` | Неоновое раскрытие | Узкая граница раскрытия слева направо подсвечена голубым и розовым неоновым свечением. |

Все двадцать переходов допускают статичные фото, анимированные GIF, видео и
специальные экраны в любой паре. Они работают с живыми слоями виджетов:
видеокадры и GIF не заменяются снимком. Возможность воспроизведения видео
по-прежнему зависит от платформы/runtime; переход не добавляет видеоплеер
на неподдерживаемую платформу.

Soft Wipe и Light Sweep применяют градиентную маску слоя. Luma Fade вычисляет
прозрачность по яркости через цветовую матрицу, без чтения кадров на CPU.
Slice создаёт восемь визуальных представлений исходящего медиа, использующих
общие подготовленные изображения, GIF image stream или одну видеосессию;
отдельный декодер для каждой полосы не создаётся. Page Peel обрезает один живой
слой и рисует обратную сторону листа отдельно: изображение на бумажной
обратной стороне не дублируется.

Light Leak рисует градиентную засветку поверх смешивающихся живых слоёв.
Film Roll и Whip перемещают два слоя целиком и применяют направленное размытие;
Cross Zoom использует масштабирование и обычное двумерное размытие, без
радиального shader-фильтра. Сила размытия зависит от размера viewport и плавно
возвращается к нулю в конце. Glass моделирует плоские стеклянные грани
геометрическими смещениями и масштабированием; это не непрерывная попиксельная
рефракция. Он создаёт по восемь представлений каждого слайда, сохраняя одну
видеосессию на исходящее и одну на входящее видео. Исходные фото для этих
эффектов дополнительно не декодируются и не уменьшаются.

Film Roll, Cross Zoom, Whip и Glass добавляют композиционные слои/размытие;
их стоимость на устройстве ещё не измерена.

Clock Wipe, Panel Wipe и Star Wipe используют одну маску над одним живым
входящим слоем. В Panel Wipe полосы — части общей маски; виджеты медиа не
дублируются. Split имеет два представления исходящего слайда и одно входящего,
с общими подготовленными изображениями/GIF image stream и одной видеосессией
на каждое медиа. Stretch использует два живых слоя с горизонтальным
масштабированием и прозрачностью. Геометрическая пятёрка не добавляет собственных
таймеров, декодеров, снимков кадров или GPU-шейдеров. Размытие, плотность
прежних Mosaic/MosaicFade и подготовка изображений сохраняются.

Film Dissolve сохраняет по одному живому представлению каждого медиа. Цветовые
фильтры преобразуют sRGB в линейное пространство перед смешиванием и обратно
после него. В середине перехода чёрный→белый даёт примерно 188/255 вместо
128/255 у обычного Fade. Конечные кадры проходят без gamma-преобразования,
чтобы сохранить исходные пиксели; в промежуточных кадрах возможна небольшая
погрешность округления цвета.

Frame использует одну прямоугольную маску входящего слоя, окантовку и тень.
Louver имеет по восемь визуальных представлений каждого медиа; обратная
сторона планки корректируется вторым поворотом, поэтому входящий текст не
зеркалится. Все планки используют одну видеосессию на каждое медиа. Mirror
имеет по два представления каждого слайда: основное и зеркальное, также с
общими сессиями. Neon Wipe использует существующий механизм Soft Wipe с узкой
маской и отдельной градиентной подсветкой. Прежние ширина границы Soft Wipe и
рисунок Light Sweep сохраняются; кеш маски сбрасывается при смене стиля/размера.
Эти переходы не создают снимков видео и не декодируют дополнительные копии
медиа. Дополнительные слои Film Dissolve/Louver/Mirror и тень Frame требуют
отдельной оценки на устройстве; аппаратных измерений этой пятёрки нет.

Начальный и конечный кадры совпадают с исходящим и входящим слайдами;
подготовка фото и разрешение исходных изображений не меняются. Ken Burns, пауза,
сон и возобновление продолжают использовать существующие сессии и
`FixedAnimationController`. Под нагрузкой этот контроллер намеренно замедляет
переход. Точное совпадение wall time с заданной длительностью не гарантируется.
Прозрачные участки и поля видео имеют чёрную подложку внутри каждого слайда,
чтобы другой кадр не просвечивал через них до начала перехода.

## Настройка

В настройках слайдшоу выберите переходы в списке разрешённых эффектов.
Все двадцать также доступны в выпадающем списке предпросмотра с русскими и
английскими подписями; выбор немедленно запускает демонстрацию. Отдельных
параметров этих эффектов в форме нет. Длительность задаёт общее поле
`transitionTimeMs`, например:

```json
{
  "slideshow": {
    "allowedEffects": [
      "Soft Wipe", "Light Sweep", "Slice", "Luma Fade", "Page Peel",
      "Light Leak", "Film Roll", "Cross Zoom", "Whip", "Glass",
      "Clock Wipe", "Split", "Panel Wipe", "Stretch", "Star Wipe",
      "Film Dissolve", "Frame", "Louver", "Mirror", "Neon Wipe"
    ],
    "transitionTimeMs": 1000
  }
}
```

Пустой `allowedEffects` разрешает весь реестр, включая новые переходы.
Имена API остаются английскими независимо от языка панели; прежние имена и
поведение разбора неизвестного имени сохранены. Локализованные подписи
хранятся в ARB; генерация — `flutter gen-l10n` из `i18n/`.

## Локальные проверки

Из `dslideshow_flutter/`:

```sh
flutter analyze --no-pub
flutter test --no-pub
```

Из `config_app/`:

```sh
flutter analyze --no-pub
flutter test --no-pub
flutter build web --release --no-pub --no-web-resources-cdn
```

Новые регрессии находятся в `premiere_transitions_test.dart`,
`transition_media_selection_test.dart`, `video_session_test.dart` и
`premiere_transitions_preview_test.dart`.
Они проверяют пиксели начального/конечного и промежуточных кадров, раскрытие
по яркости, мягкую границу и блик, смещение полос, обратную сторону листа,
движение засветки, направления прокрутки/панорамы, размытие, увеличение
исходящего кадра и смещение деталей в стеклянных гранях,
направление часового сектора, смещение половин Split, порядок панелей,
горизонтальное растяжение и форму звезды,
линейное смешивание света, прямоугольную рамку, поворот планок Louver,
зеркальную половину, неоновую границу и смену кеша маски,
сохранение состояний живых слоёв, выбор из сохранённой конфигурации,
локализацию, предпросмотр и отмену при быстрой смене эффектов.
Общая локальная галерея кадров автоматически включает новые эффекты:
`flutter test --no-pub tool/render_effect_gallery_test.dart` из `benchmarks/`,
результат — `benchmarks/build/effects/gallery-*.png`.

По указанию пользователя проверка на устройстве для этой работы не выполняется.
Локальные тесты и web-сборка не подтверждают производительность, визуальное
качество native Texture или стабильность видеоплеера RaPi5. Аппаратных
измерений новых переходов нет.
