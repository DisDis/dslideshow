# DEB 18.0.0+1 — 31 октября 2026

Мажорный выпуск поверх `c6d241dd`. Исходное рабочее дерево содержало
версии `17.1.0+7`; подготовлена версия `18.0.0`, затем штатный
`deb_factory/build.sh --no-color --no-progress` собрал `18.0.0+1`.
[Changelog](../../../changelog.md), [порядок выпуска](../../releasing.md).

## Состав

Яндекс Диск с несколькими аккаунтами и выбором папок, скрытые медиа,
обнаружение рамок и импорт папок на Android. Консоль и журнал службы
сохраняют исходные исключения и полные стеки, включая диагностику HTTP
Яндекс Диска. Пути, URL и реквизиты в диагностике не маскируются;
см. [правила логирования](../../logging.md).

## Проверки

Полный конвейер завершился успешно: ARM64 AOT для CPU pi4, web Wasm
с JavaScript fallback, анализаторы без замечаний и 1860 тестов:
common 40, RPC-генератор 23, backend 780, i18n 3, системные виджеты 10,
frontend 349, config_app 540, обязательные сборочные тесты tools 115.
Дополнительно прошли 23 теста YandexDriveApi, включая исходные ошибки,
стек в LogRecord и конечный консольный вывод.

Проверены Package/Version/Architecture/Description, обе production-версии,
ApplicationInfo, установленный файл version и все 144 MD5 содержимого DEB.
Native runtime совпадает со входом сборки и предыдущим выпуском.
Метаданные path-зависимостей обновлены через `pub get --offline`.
Полный каталог тестов tools отдельно не запускался.

## Границы приёмки

DEB не установлен на фоторамку и не опубликован в OTA. Браузерные,
аппаратные проверки и сборка Android APK в этом выпуске не выполнялись.
Hot reload не выполнялся: при подготовке менялись только версии и документация,
код поведения приложения не менялся. Локальные тесты не подтверждают
реальную авторизацию облака, Android picker или работу GPU на устройстве.
