# DEB 19.0.0+1 — 31 октября 2026

Мажорный выпуск поверх `17fa710e`. Исходное рабочее дерево было чистым,
production-версии — `18.0.0+6`. Штатный генератор подготовил `19.0.0`,
затем `deb_factory/build.sh --no-color --no-progress` собрал `19.0.0+1`
за 227,6 с. [Changelog](../../../changelog.md), [порядок выпуска](../../releasing.md).

## Состав

Статус активного хранилища в телеметрии и панели управления, отдельное состояние
ошибки с постоянным красным значком на рамке, сохранение ошибки частичной
облачной синхронизации. Сравнение дубликатов учитывает даты, разрешение,
сопоставимую оценку сжатия JPEG и размер при одинаковых параметрах;
показывает независимые цвета показателей и предварительность рекомендации.
Подробности — в [backend](../../../backend/README.md),
[руководстве устройства](../../config-app-device.md) и [галерее](../../gallery.md).

## Проверки

Полный штатный конвейер прошёл с первой попытки: ARM64 AOT для CPU pi4,
web Wasm с JavaScript fallback, все анализаторы с `No issues found` и
1879 тестов: common 41, RPC-генератор 23, backend 792, i18n 3,
системные виджеты 10, frontend 349, config_app 546, сборочные тесты tools 115.
Полный набор tools отдельно не запускался.

Проверены Package/Version/Architecture/Description, обе production-версии,
ApplicationInfo, staging control и установленный файл version; все 144 MD5
содержимого DEB совпали. SHA-256 native runtime совпадает со входом сборки
и выпуском 18.0.0+1. Lock-файлы path-зависимостей синхронизированы
через `pub get --offline`, сторонние зависимости не обновлялись.

При ревью диагностики проверены существующие логи синхронизации и сравнения:
начало/итог, частичный отказ, исходное исключение и стек, FINE-сводки сравнения.
Регрессии логов и состояний входят в прошедшие backend/VM-тесты.
Документация галереи и хранилища отражает изменения; открытые планы и
индекс benchmarks сохраняют границы прежних аппаратных результатов.
Ссылки записи выпуска и индекса выпусков проверены локально, архивы не менялись.
При аудите обнаружено, что локальные материалы из индекса benchmarks отсутствуют:
например, `maintenance-2026-10-29/report.md` ранее удалён в `bdb07ad1`.
Ссылки на прежние архивные отчёты не подтверждают их локальную доступность;
полная проверка этих исторических материалов в этот выпуск не входит.

## Границы приёмки

DEB не установлен на фоторамку и не опубликован в OTA. Браузерные,
аппаратные проверки и сборка Android APK не выполнялись. Версия Android
в config_app/pubspec.yaml сохраняется от предыдущей сборки APK;
при следующем запуске build_android.sh она будет взята из backend.
Hot reload не требовался: при подготовке изменены только версии,
lock-файлы и документация. Локальная приёмка не подтверждает живой OAuth,
Android picker, GPU и производительность на физической рамке.
