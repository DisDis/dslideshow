# DEB 15.0.0+1 — 29 октября 2026

Мажорный выпуск после `14.1.0`: обновлённый OTA, перенос конфигурации,
выбор языка фоторамки и Wasm-панель. Исходный коммит перед подготовкой —
`0a374772e5e3920e42d815da0cc49e7cc5ae0b5e`.
Продуктовые изменения перечислены в [changelog](../../../changelog.md).

## Изменения и совместимость

* Экран OTA сохраняет крупные QR, жирный код доступа и красную текущую версию.
  Журнал установки занимает всю ширину со шрифтом 32 px; просмотр истории
  приостанавливает автопрокрутку, кнопка возвращает к новым строкам.
  Проценты показываются только при передаче файла. Поздняя инициализация
  не сбрасывает уже начатую стадию обновления. [Экран и проверки](../../../dslideshow_flutter/README.md#терминал-ota).
* Встроенные русские/английские страницы OTA объединяют прошивку,
  резервное копирование и импорт `config.json`, а также возврат к слайдшоу.
  Скачивается исходный файл, включая повреждённый JSON. Импорт проверяет модель
  и атомарно заменяет файл, сохраняя исходные байты и неизвестные поля;
  ошибка оставляет прежнюю конфигурацию. Импорт применяется после перезапуска.
  Неверный код прошивки возвращает страницу ошибки после ограниченного
  дочитывания отклонённой передачи. HTTP 200 означает приём пакета;
  результат установки показывается на рамке. [Контракт и пределы](../../uploads.md).
* Поле `language` и отдельный выбор языка рамки в config_app: `en` по умолчанию,
  `ru` или явный `system`. Отсутствующее, `null` и неизвестное значение дают
  английский. Язык применяется после сохранения и перезапуска приложения;
  язык панели остаётся независимым. HTML-страницы OTA выбирают язык по
  `Accept-Language`. [Настройка языка](../../language.md).
* Панель собирается с WebAssembly/skwasm и JavaScript/CanvasKit fallback.
  Все renderer-ресурсы включены в DEB; переносится весь web bundle.
  На штатном HTTP-сервере используется однопоточный skwasm.
  [Сборка и ограничения](../../../config_app/README.md).

Формат `slideshow.effects` сохраняется с версии 14.0.0; новых несовместимых
изменений этого блока нет. Старые `allowedEffects`/`transitionTimeMs`
по-прежнему игнорируются, без нового блока используется Fade.
Перед обновлением сохраните конфигурацию. [Формат настроек](../../effect-settings.md).
OTA работает внутри процесса Flutter и недоступен при его отказе;
отдельной recovery-службы нет.

## Проверки

До сборки `./deb_factory/run_analysis.sh` проверил все 10 Dart/Flutter-пакетов:
в каждом `No issues found`, включая отсутствие `info`.
Штатный `deb_factory/build.sh` повторил анализ и обязательные локальные тесты,
параллельно успешно собрав AOT и web-панель. Всего прошли 1157 Dart/Flutter-тестов
и 39 Python-тестов.

| Набор | Результат |
| --- | --- |
| common | 28 тестов |
| rpc_serializers_generator | 23 теста |
| backend | 486 тестов, последовательно |
| i18n | 3 теста |
| system_metrics_widget | 10 тестов |
| dslideshow_flutter | 273 теста |
| config_app | 334 теста |
| Python: Linux tools / упаковка | 6 / 33 теста |

Браузерные и desktop integration-тесты в этой подготовке не запускались.
VM-тесты и успешная Wasm/JavaScript-компиляция не проверяют запуск панели,
DOM, отправку HTML-форм и выполнение скриптов в настоящем браузере.
Реальная установка OTA, отключение питания и язык окружения flutter-pi
не входят в локальное покрытие. [Границы проверок](../../testing.md).

## Аппаратные данные

Использован сохранённый [OTA UX A/B на RaPi5/OpenGL от 29.10.2026](../../../benchmarks/reports/ota-ux-2026-10-29/report.md).
SHA-256 архива `candidate-frozen/source.tar.gz` сверен с отчётом:
`ac6e2f2156781e7584d4b1a70330527dff6b90b7b09a1dcf2edf2d10d2d716ad`.
Все 133 файла `dslideshow_flutter/lib/` и 4 файла локализаций совпали с этим
кандидатом; в `common/lib/` отличается только сгенерированная версия.
Отчёт сохраняет release baseline/candidate, потоковые проверки терминала,
FrameTiming и отдельные PNG всех стадий. Подменён только внешний сервис:
реальная загрузка, установка и перезапуск там не выполнялись.

Это короткая проверка выбранного UX, без заявления об ускорении или длительном
отсутствии утечек. Аппаратный стенд использовал CPU pi5 и свой bundled engine;
финальный DEB использует штатные CPU pi4/engine. Его установка и полный
аппаратный прогон в рамках подготовки не выполнялись. Измерения стенда
не являются численной приёмкой производительности этого DEB или всего каталога.
Команды повторения сохранены в [OTA harness](../../../benchmarks/ota-harness.md)
и [руководстве RaPi5](../../raspberry-pi-benchmarks.md).

Перед подготовкой read-only SSH подтвердил active-службу `dslideshow`,
установленную версию `14.1.0+11` и совпадение рабочего runtime с подготовленным
бинарником. Новых GPU-прогонов и остановок службы не было; ОС, драйверы,
прошивка и flutter-pi не изменялись. Vulkan и 24-часовой прогон не запускались.

После распаковки DEB проверены все 142 MD5, полнота манифеста и относительные
