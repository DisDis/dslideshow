# Продолжение GPU-оптимизации: Radial Blur и VHS

28.10.2026 после установки пользователем нового flutter-pi и изменения частот
baseline снят заново. В штатные фабрики перенесены два измеренных улучшения:
общие координаты выборки Radial и кеширование стабильных цветовых слоёв VHS.
Все девять лучей Radial, разрешение фото, параметры, noise/полосы VHS и
`FixedAnimationController` сохранены.

## Условия

RaPi5 2 GiB, OpenGL, 2560×1600, DPR 1, дисплей около 50 Hz. Flutter 3.47.7 /
Dart 3.13.5; engine SHA
`c466d00c4a274e78bb31589ae6cf261ac6a3c447cc980f879d49c94c48537523`.
Установленный runtime во всех запусках:
`30669efa6ad054744b4c63275cafaf7738d1489b5702c17de666ac73edcbea4b`.
На устройстве наблюдался checkout `cfbc44a556931e7ccf647d46f7165062450e9a95`;
сборку/установку runtime выполнял пользователь, эта работа его не подменяет.

В firmware config закреплены CPU max 2600 и V3D/GPU max 900 МГц. Частоты,
температуры и throttling записаны отдельным наблюдателем каждые пять секунд.
DVFS снижает частоту в простое; это не означает throttling. Сопоставимость
проверяется по конфигурации и наблюдаемой нагрузке, а не по единственному снимку
частоты. Старые результаты на runtime `9e609…d67` с этими числами не смешиваются.
Во всех шести ABBA наблюдался `throttled=0x0`; температура 51,6–60,9 °C.
Сводка исходных пятисекундных наблюдений — `clock-summary.json` рядом со
сводкой сравнений.

Входы — те же JPEG 4032×3024 и 6000×4000, подготовленные `ImageWidget` до
2560×1600. `production_photo_inputs=true`, фото→фото; без видео, GIF, 48-Мп,
Vulkan и 24h. AOT release, отдельные frozen source/release архивы с manifest и
проверкой распаковки. Живые lock-файлы/версии не менялись; stale path-version
metadata нормализована только в изолированных копиях перед offline pub get.

Каждая проверка — ABBA: baseline, candidate, candidate, baseline. Между запусками
supervisor восстанавливает службу. Runtime/config/bundle SHA проверяются перед
каждым процессом. В FPS-процессах нет interposer/readback. На сторону получается
четыре измерения Radial и шесть VHS; каждый процесс сначала прогревает сценарий.

## Производительность

Ниже медианы первой пары и p95 объединённых measured FrameTiming этой пары.
Обратная пара подтверждает тот же результат. Sampled FPS — счётчик Flutter,
не число уникальных физических scanout; у контролей Baseline/Fade около 60 FPS.

| Эффект | FPS до → после | Прирост | Raster p95, мс до → после |
| --- | ---: | ---: | ---: |
| Radial Blur | 5,83 → 9,43 | +61,79% | 174,69 → 107,98 |
| VHS Damage | 15,31 → 23,17 | +51,35% | 69,03 → 45,94 |

Обе пары сопоставимы, все ожидаемые повторы и прогревы присутствуют, ошибок нет.
Порог 25 FPS пока не достигнут. Это подтверждённые выигрыши отдельных путей,
а не новый скрининг всех 37 семейств / 82 пресетов.

Radial вычислял одинаковые contain/UV для каждого фото отдельно. Новый путь
использует одну координату и два texture lookup только при точном совпадении
размеров обоих фото с viewport и identity outgoing camera. Цикл из девяти лучей,
тригонометрия, границы, black backing, source-over и bilinear sampling прежние.
Другие размеры или PhotoMotion-камера сохраняют независимые вычисления.

В VHS `BlendMode.modulate` линеен: стабильные tinted-входы вынесены перед
меняющимся смешиванием и получили `RepaintBoundary`. Меняются прежние opacity,
смещения и tracking; цветовой слой может переиспользоваться. Штатный
`PhotoVhsDamageEffect` включает этот путь только после `bindPhotos` для двух
подготовленных фото. Null сбрасывает его к исходной живой композиции. Сам эффект
не удерживает и не клонирует bitmap; камера уже содержится во входных виджетах.

В первой паре sampled process RSS peak Radial 339,08 → 344,95 MiB,
VHS 360,91 → 357,13 MiB. Это не GPU-память и не проверка утечки. У VHS-кандидата
системный SwapFree уменьшился на 1 MiB; наблюдение сохранено, оно не доказывает
причинный swap I/O эффекта. Остальные ресурсы/хвосты доступны в raw и сравнениях.

## Качество

Независимый локальный Radial shader fixture сохранён в
`benchmarks/shaders/radial_shared_uv_reference.frag`, SHA
`f44658804c0eec4f0fec015477a82464aa5802839f97a1b61c14e64a26a65e5b`.
Тест сверяет все origins, углы, identity/PhotoMotion-камеры, разные аспекты,
перепривязку и освобождение shader при сохранении чужих фото. Проверяемая
матрица дала max delta 0. VHS локально дал max delta 2 на контрастных/прозрачных
фото с разными настройками; проверены фабрика и возврат к живым входам.

Отдельный release EGL-аудит прочитал настоящий FBO0 после трёх соседних фаз
прогрева и на первом swap целевой фазы. Реально загруженные engine/PID и runtime
проверены по native provenance. Без внешнего `RepaintBoundary.toImage`;
physical scanout не проверяется. FPS этого процесса не используется.

* Radial: все три фазы .25/.5/.75 совпали **побайтно**.
* VHS: фазы .25/.75 — max delta 1. В .5 max delta 32, средняя разница по всем
  каналам 0,03436/255. Все 1392 пикселя с delta>2 лежат в одном столбце x=89
  из 2560×1600: граница сдвинутой кешированной текстуры. Это 0,034% пикселей.

Strict max2 для VHS **не пройден**, исходный failed-статус сохранён. В том же
аудите проверялся впоследствии отвергнутый Canvas Kaleidoscope (max3), поэтому
общий exit=2 не превращён в успешную приёмку. Runtime ошибок не зарегистрировано,
служба восстановлена. Попытка hard clip границы отвергнута локально: она меняла
исходное сглаживание. Пределы проверок не ослаблялись ради переноса.

После ручного сравнения в config_app пользователь принял визуальный результат
VHS и разрешил удалить эталон. Временный переключатель сравнения, его состояние
и локализации удалены; preview использует основной ускоренный вариант.
Исходная композиция VHS остаётся необходимым fallback для живых входов.
Ручное принятие не изменяет приведённые выше численные результаты EGL-аудита.

## Проверка штатной интеграции

После переноса выполнен отдельный release-прогон обычного `benchmarks/lib/main.dart`
с Baseline, Fade, Radial и VHS: один прогрев и два измерения на сценарий.
Run ID `20261028T160735Z-smoke-b2gnz9tE`, все четыре сценария и восемь измерений
успешны, ошибок нет. Медианы sampled FPS: Baseline/Fade около 60,
Radial 9,43, VHS 23,21. Это проверка подключения фабрик и viewport после переноса;
проценты улучшения выше взяты из отдельных сопоставимых ABBA.

Финальный source SHA
`f417f24a9eac21470857760045076cef44fb943b1f2e0ae75e533a8841e9b50a`,
app.so SHA `31688f705f5ca4343598e5069574e4b32db0cce5e8cc29f30b6c834c2348c287`.
Supervisor завершился с кодом 0, `dslideshow` восстановлен, runtime SHA прежний,
throttling отсутствует. Установленное основное приложение этим прогоном не заменялось.

Локально прошли 216 тестов приложения, 76 тестов стенда, 30 релевантных тестов
preview/редактора и release web-сборка config_app. Анализатор стенда чист;
в приложении остались семь прежних style/deprecation info, в config_app — пять
прежних initializing-formal info; новых ошибок/предупреждений нет.
Проверены форматирование изменённых Dart-файлов, локальные ссылки и `git diff --check`.

## Отклонённые варианты

| Попытка | FPS baseline → candidate | Решение |
| --- | ---: | --- |
| Kaleidoscope: общий shader blend, native high samplers | 8,17 → 6,27 | медленнее |
| VHS: тот же shader blend | 15,31 → 8,89 | медленнее |
| Kaleidoscope: ручной Mitchell, 9 bilinear lookup | 8,17 → 6,04 | медленнее |

У CPU rotations дополнительно не прошли строгие численные границы на contain
discontinuities; статус сохранён. Временные классы/entrypoints удалены из живых
исходников после архивации. Kaleidoscope остаётся прежним; Glow, Glass и
CrossZoom в этом раунде не изменялись.

source/release, а не текущие исходники. Новые конфиги Radial/VHS измеряют уже
штатные фабрики. Команды запуска и supervisor — в
[аппаратном руководстве](raspberry-pi-benchmarks.md), локальные проверки — в
[README стенда](../benchmarks/README.md#radial--vhs-после-обновления-flutter-pi-и-частот).
