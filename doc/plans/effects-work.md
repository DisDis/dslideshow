Последний полный холодный скрининг из раннего каталожного исследования
не повторялся после всех последующих переносов. Его число медленных эффектов
относится к сохранённой сборке; это не текущий результат. Возможное продолжение
исследования выбирается по измерениям: для Kaleidoscope остаётся проблема
границ/anti-aliasing, у Glow не найдено безопасного упрощения Gaussian/gain-clamp.
Принятые Radial UV и VHS tint cache описаны в
[последующем GPU-отчёте](../../benchmarks/reports/gpu-effects-2026-10-28/report.md);
не следует повторять их как ещё не реализованные предложения.
BlurFade без отдельного поручения повторно не оптимизируется.

## Подготовленные сценарии и ограничения

Текущие конфиги и состав матрицы определяет [README стенда](../../benchmarks/README.md).
Для дополнительной диагностики персональных параметров сохранены
[effect-options-visual.json](../../benchmarks/config/effect-options-visual.json) и
[effect-options-performance.json](../../benchmarks/config/effect-options-performance.json):
они используют production-эффекты, текущие defaults/пресеты и крайние options.
Ранние временные рендеры и попарные эталоны пресетов удалены после принятия;
для аппаратного A/B они не заменяют отдельный release baseline.

Проверки на RaPi5 выполняются по [единому руководству](../raspberry-pi-benchmarks.md)
через supervisor с восстановлением службы. ОС, драйверы, прошивка и рабочий
runtime в рамках эффектов не меняются; обычные запуски — только OpenGL.
`FixedAnimationController`, оригиналы, sampling, плотность Mosaic 100×100
и дополнительные сетки 150×150/200×200 сохраняются. Видеопадение остаётся
ошибкой с active-operation и native.log. Методика локальных тестов — в
[общем руководстве](../testing.md); код и телеметрия стенда — только в `benchmarks/`.

Каждый новый этап завершается воспроизводимым отчётом, обновлением индекса,
фиксацией оставшихся ограничений и удалением завершённых временных реализаций
по [правилам сопровождения](../benchmarks-maintenance.md). Исторические A/B
не переобозначаются как приёмка последующего кода.
