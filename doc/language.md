# Язык фоторамки и панели настройки

Язык локализованного интерфейса фоторамки, в том числе экрана OTA, задаётся
корневым полем `language` в `config.json`:

```json
{
  "language": "ru"
}
```

| Значение | Поведение |
| --- | --- |
| `system` | Явно включить язык окружения приложения рамки; для неподдерживаемого языка — английский. |
| `en` | Английский независимо от языка окружения; значение по умолчанию. |
| `ru` | Русский независимо от языка окружения. |

Отсутствующее поле, `null` и неизвестное значение также выбирают `en`.
Сериализация модели возвращает явное значение enum; компактная запись
`toStorageJson()` удаляет `en` как значение по умолчанию. Явные `system` и `ru`
сохраняются. Остальные настройки JSON при этом обрабатываются как прежде.
Допустимые значения задаёт `FrameLanguage` в [модели конфигурации](../backend/lib/config.dart).

В config_app откройте основную форму настройки и раздел **Интерфейс фоторамки**.
Выберите **Язык фоторамки**, нажмите **Save** и выполните штатный перезапуск
приложения рамки через управление системой. До Save выбор остаётся в черновике;
**Reload** и выход с несохранённым изменением требуют обычного подтверждения.
Save и Reload сами не меняют язык уже работающего приложения рамки.

Язык панели в меню **Оформление** — независимая настройка текущей сессии браузера
или desktop-панели. Его изменение не переписывает `language` рамки, а выбор языка
рамки не переключает язык панели. Встроенные HTML-страницы OTA и восстановления
конфигурации выбирают язык по `Accept-Language` HTTP-запроса и не используют
это поле. Системный журнал и вывод установщика сохраняют текст источника.

## Локальные проверки

Из соответствующих пакетов, с заранее полученными зависимостями:

```sh
# backend/
dart test test/config_test.dart test/json_strip_test.dart test/serializers_test.dart

# i18n/
flutter test --no-pub

# config_app/
flutter test --no-pub test/config_screen_test.dart test/app_preferences_test.dart

# dslideshow_flutter/
flutter test --no-pub test/frame_language_test.dart
```

После изменения моделей используйте штатную [генерацию build_runner](../dslideshow_flutter/README.md#проверки);
после изменения ARB — [генерацию локализаций](../i18n/README.md). Для повторного
запуска тестов без изменения источников генерация не требуется.

VM-тесты проверяют JSON, defaults, сохранение и
перезагрузку черновика панели, независимость языка панели и подключение языка
к `MaterialApp` фоторамки. Они не запускают web bundle и не проверяют язык
окружения `flutter-pi` на реальном устройстве. Для запуска браузера требуется
отдельное согласие; [правила и границы VM-покрытия](testing.md#браузерные-проверки).
