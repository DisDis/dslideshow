# Аппаратные эксперименты

Исторические отдельные пробы GPIO, PIR, кнопок, светодиодов и LD2410.
Они не являются штатными средствами запуска фоторамки или автоматической
аппаратной приёмкой текущего приложения. Проверенное подключение и актуальность
проб перед использованием нужно установить отдельно; аудит документации
29.10.2026 их не запускал и содержимое не менял.

* `py_gpio/` — Python/shell-пробы GPIO и датчиков. Они обращаются к настоящему
  оборудованию; не запускайте их как обычные локальные тесты репозитория.
* [LD2410](LD2410/README.md) — отдельная библиотека/пример, записанная в Git как
  gitlink. Корневой `.gitmodules` отсутствует; обычный новый checkout не обязан
  восстановить её содержимое. Перенос или исправление структуры подмодуля
  требует отдельной задачи.

Рабочее поведение приложения описано в руководствах
[сна и присутствия](../screen-presence.md) и [системных датчиков](../sensors.md).
Правила аппаратных запусков находятся в [руководстве RaPi5](../raspberry-pi-benchmarks.md).
