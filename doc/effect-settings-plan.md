# Персональные настройки эффектов — согласованный план

Дата: 27.10.2026; уточнение формата — 28.10.2026. Статус: **согласован с уточнением хранения длительности;
реализовано; локальные проверки выполнены**.

Подтверждено пользователем:

* Обратная совместимость старых настроек не требуется.
* Эффекты, различающиеся настройками одного алгоритма, нужно объединить:
  один эффект с параметрами вместо отдельных записей каждого варианта.
* Персональная длительность хранится в `options.durationMs`; значение `0`
  означает использование глобальной длительности.
* `items` — `Map<EffectType, EffectConfig>`; `type` внутри `EffectConfig` нет.
* Валидация полей и Save выполняется только в `config_app`.
* Каждый эффект удаляет default-параметры при записи. Обычный `stripDefaults`
  может удалить пустой раздел; отсутствующий и пустой наборы используют Fade
  на стороне рамки. Специальное сохранение явного набора отменено.
* Остальные решения плана согласованы.
* Модели данных используют Freezed, ручная реализация `copyWith` исключена.
* Предпросмотр каталога запускается между фотографиями; кнопка «Повторить»
  повторяет последнюю фотопару с текущими параметрами эффекта.
* Позднейшее уточнение пользователя: аппаратные прогоны, включая OpenGL A/B
  на RaPi5, в этой работе не выполнять. Приёмка ограничена локальными проверками.

## 1. Исходное состояние

* `backend/lib/src/service/slideshow/slideshow_config.dart` хранит
  `Iterable<String> allowedEffects` и общую `transitionTimeMs`.
* Пустой `allowedEffects` включает весь реестр. Неизвестное имя в
  `Effect.parse` превращается в `Default`.
* При подготовке плана в `Effect.values` 81 запись, включая новые Creative-
  переходы. Часть — направления, цвета и стили одного эффекта.
* `MosaicFadeEffect` уже принимает `gridSize=100`, `fadeFraction=0.3` и
  `direction`; фабрика реестра не передаёт произвольную `fadeFraction`.
* config_app показывает multiselect всех эффектов и отдельный dropdown
  предпросмотра. Выбранный для просмотра эффект не является редактируемой
  записью настроек. Предпросмотр и рамка используют общую длительность.
* Рамка выбирает эффекты перемешанными проходами с фильтром совместимости
  медиа. При отсутствии совместимого эффекта используется Fade.
* Сохранённый конфиг применяется к рамке после перезапуска. config_app уже
  имеет общий черновик, Save/Reload и защиту несохранённого/невалидного ввода.

При реализации сначала повторно проверить git status и актуальный реестр;
сохранить чужие незавершённые изменения, если они есть. План не требует
отката существующих эффектов или выпуска новой версии.

## 2. Формат хранения

Вместо `allowedEffects` и `transitionTimeMs` — подраздел `slideshow.effects`.
В нём одна запись на тип эффекта, включённость и `options` с длительностью
и параметрами соответствующего типа. Несколько профилей одного
типа, веса и сценарии порядка показа в первую реализацию не входят.

Пример полного фрагмента с тремя настроенными эффектами:

```json
{
  "slideshow": {
    "effects": {
      "schemaVersion": 1,
      "defaultDurationMs": 1000,
      "items": {
        "fade": {
          "enabled": true,
          "options": {
            "durationMs": 800
          }
        },
        "mosaic": {
          "enabled": true,
          "options": {
            "durationMs": 1800,
            "gridSize": 100,
            "fadeFraction": 0.3,
            "direction": "topLeft"
          }
        },
        "slide": {
          "enabled": false,
          "options": {
            "durationMs": 0,
            "mode": "push",
            "direction": "left"
          }
        }
      }
    }
  }
}
```

Правила формата:

| Ситуация | Поведение |
| --- | --- |
| `options.durationMs=0` | Использовать глобальную `defaultDurationMs`; изменение общего значения действует только на такие эффекты. Это наследование, а не мгновенный переход. |
| `options.durationMs` — положительное целое | Использовать персональную длительность в миллисекундах. |
| `options.durationMs` отсутствует или `null` | Прочитать как `0`; при записи в файл default `0` можно опустить. |
| `enabled` отсутствует | `false`; включение всегда явное. |
| Параметр `options` отсутствует | Использовать default этого типа. |
| Тип отсутствует в `items` | Выключен; каталог показывает его default, запись создаётся при включении или изменении. |
| `enabled=false` | Сохранить длительность и параметры, исключить из выбора. |
| `items={}` или все записи выключены | Не включать весь каталог. Использовать служебный Fade с общей длительностью и показать пояснение в панели. |
| Совместимых с парой медиа эффектов нет | Тот же служебный Fade. Его настройки фиксированы, длительность общая; персональная запись Fade на fallback не влияет. |
| Весь `effects` отсутствует | Пустой набор; рамка использует служебный Fade с общей длительностью. |
| Блок `effects` есть, `items` отсутствует | Считать пустым набором. `schemaVersion` по умолчанию 1, общая длительность 1000 ms. |
| Новый тип добавлен в каталог | В существующем явном наборе остаётся выключенным до выбора пользователя. |
| Уникальность типа | Карта хранит одно значение для каждого `EffectType`. |

При сериализации `toJson()` модели options убирают свои default-параметры;
`EffectConfig` — пустые options и default-включённость, `EffectsConfig` —
пустые записи и defaults раздела.
Выключенные эффекты с персональными options сохраняются. Генерируемый
`SlideShowConfig.toJson()` сам вызывает `effects.toJson()`; дополнительного
переопределения эффектов при записи нет. `AppConfig` использует обычный
`stripDefaults`. Никакой блок не требуется сохранять принудительно:
отсутствующий и пустой наборы имеют одинаковое поведение на рамке.
В значении `EffectConfig` поля `type` нет; персональная длительность находится
только внутри `options`. Порядок ключей не задаёт порядок проигрывания.

Эффективная длительность вычисляется единообразно:
`options.durationMs == 0 ? defaultDurationMs : options.durationMs`.

Ключ карты — стабильный идентификатор enum с JSON-представлением, например
`mosaic`. Имя класса, `runtimeType`, локализованная подпись и отображаемое имя
не участвуют в хранении. Строки типов/режимов используются только на границе
JSON; модели, каталог, формы и выбор эффекта работают с enum.

Старые поля не читать, конвертеры старых имён не добавлять и двойную запись
форматов не делать. Если в старом файле нет `effects`, используется служебный
Fade; при следующем сохранении старые поля исчезают.
При реализации явно документировать это изменение формата. `displayTimeMs`,
`photoMotion`, специальные экраны и `fadeTimeMs` затухания экрана сохраняют
свой самостоятельный смысл.

## 3. Объединение дубликатов

Таблица канонических эффектов:

| Текущие записи | Одна запись каталога | Настройки |
| --- | --- | --- |
| Mosaic, MosaicFade, MosaicTL/TR/BL/BRFade | `mosaic` / «Мозаика» | `gridSize`, `fadeFraction`, `direction`; бинарная Mosaic — `fadeFraction=0`. |
| Default, Push Right/Up/Down, Cover Right/Up/Down, Reveal Left/Right/Up/Down | `slide` / «Сдвиг» | `mode: push/cover/reveal`, `direction: left/right/up/down`; Default соответствует push влево. |
| Wipe Left/Right/Up/Down, Curtain Horizontal/Vertical, Diagonal ×4, Iris | `revealMask` / «Раскрытие маской» | `shape: wipe/curtain/diagonal/iris`, направление/ось/начало раскрытия для выбранной формы. |
| Fade Through Black / White | `fadeThroughColor` / «Через цвет» | Цвет; чёрный и белый — быстрые варианты в поле цвета. |
| Soft Wipe, Light Sweep, Neon Wipe | `softWipe` / «Мягкое раскрытие» | `style: soft/lightSweep/neon`. |
| Flip Horizontal / Vertical | `flip` / «Переворот» | Ось вращения. |
| Rotate Up / Down | `rotate` / «Поворот» | Верхняя/нижняя точка поворота, угол. |

Удалить отдельные записи вариантов из реестра, селекторов, локализаций
каталога и текущих benchmark-наборов. Не оставлять скрытые aliases старых
названий. Старые отчёты и архивы остаются историческими материалами.

Таблица задаёт объединение пользовательских вариантов, а не требование иметь
один Dart-класс на строку: внутренние реализации можно переиспользовать.
При сведении Default к `slide` отдельно проверить clipping, порядок слоёв
и конечные кадры. Для Flip и Rotate сохранить перспективу и геометрию обеих
осей/точек поворота, а не только похожий средний кадр.

Разные алгоритмы остаются разными типами, даже когда технически собраны
в одном классе через `kind`: например, Light Leak / Film Roll / Cross Zoom /
Whip и десять CreativeTransition-алгоритмов. Общий файл сам по себе не делает
их дубликатами. При инвентаризации зафиксировать и остальные пары: объединять
их только при совпадении алгоритма с заменой параметров.

## 4. Модели и единый путь исполнения

* В `common/` добавить чистые Dart-модели `EffectsConfig`, `EffectConfig`,
  `EffectType`, enum параметров и типизированные options, например
  `MosaicEffectOptions` и `SlideEffectOptions`. Backend уже зависит от common;
  Flutter, `Color`, `Alignment` и `AxisDirection` в модели не импортировать.
  Все typed options имеют общее поле `int durationMs` с default `0`;
  для эффектов без других параметров используется модель базовых options.
* Использовать `@JsonSerializable()` и `@JsonKey`/конвертеры. Полиморфный
  разбор options выбирает конкретную модель по `EffectType`; обычные
  `fromJson`/`toJson` делегируют генератору. `Map<String, dynamic>` не становится
  API бизнес-логики или универсальной строковой схемой редактора.
* В backend подключить новую модель к `SlideShowConfig`, экспорту
  `config.dart`, компактному хранению и сохранению через WebSocket. Один
  валидатор расположен только в config_app; backend не проверяет диапазоны
  и сочетания параметров при сохранении.
* В `dslideshow_flutter` сделать реестр `EffectType → descriptor`:
  фабрика из typed options, группа каталога и ограничения медиа. Подписи
  и формы остаются в config_app; источник default-параметров один — модели.
* Рамка и предпросмотр вызывают одну фабрику с одной конфигурацией. В
  `SlideshowState` передаётся неизменяемый снимок выбранной настройки и
  вычисленной длительности; подготовка и запуск используют этот же снимок.
* Длительность `FixedAnimationController` назначается перед началом нового
  перехода, после подготовки ресурсов. Она не меняется посреди перехода
  или при паузе/возобновлении. Зафиксировать такой же порядок в preview.
* Сохранить перемешанные проходы без повторов до исчерпания совместимого
  набора. В пуле каждый тип встречается один раз; число его возможных
  направлений не увеличивает вероятность выбора.
* Seed для воспроизводимого preview/benchmark и Canvas/shader backend —
  контекст фабрики, а не пользовательские опции. Рабочий Canvas default
  не менять. Подготовку и ресурсы не создавать в `build`/на каждом кадре.

Начальные параметры: длительность у всех эффектов; все параметры из таблицы
объединений; число полос Blinds/Slice, панелей Glass/Panel Wipe и створок Louver.
Остальные уже существующие числовые параметры перечислить при инвентаризации;
их вывод в UI делать только с определёнными границами и тестами. Новые
визуальные алгоритмы и настройку каждого внутреннего коэффициента в этот этап
не включать.

Пределы первой реализации: глобальная длительность 1–3 600 000 ms,
`options.durationMs` — `0` для глобальной либо целое 1–3 600 000 ms для своей;
отрицательные, дробные и выходящие за границы значения невалидны.
`gridSize` — целое 100–200 с быстрым выбором 100/150/200,
`fadeFraction` — конечное число 0–1, счётчики полос/панелей — целые 1–32.
Default Mosaic: 100, 0.3, random. Здесь random означает случайный порядок
ячеек, как сейчас; случайный выбор направления из углов — другая функция
и в первую реализацию не входит. Верхние границы счётчиков проверить на
устройстве до окончательной приёмки.

Панель проверяет версию схемы, диапазоны, соответствие options ключу типа
и сочетания параметров; ошибки с путём к полю блокируют отправку Save.
В backend и рамке этих валидаторов нет. Разбор JSON обрабатывает неизвестные
ключи и ошибки типов: неизвестные ключи/необъектные значения пропускаются
с логом, известные записи с ошибкой разбора сохраняются для исправления
в панели и исключаются из проигрывания. При неподдерживаемой версии весь
блок не исполняется. При отсутствии пригодного набора применяется служебный
Fade. Файл при чтении автоматически не переписывается.

## 5. Редактор config_app

Разделить «Общие настройки слайдшоу» и отдельную страницу «Эффекты перехода».
Общие настройки сохраняют время показа, движение фото и фон. Страница эффектов
содержит общую длительность, каталог и редактор выбранного эффекта.

Схема широкого окна:

```text
Эффекты перехода                      Включено: 12 из N
Общая длительность: [1000 мс]

[Поиск по названию... ] [Все / Включённые / Изменённые]
[Группа: Все / Затухания / Движение / Маски / ...]

Каталог                         Мозаика                  [Вкл.]
  [вкл] Затухание   800 мс       [единый предпросмотр A → B]
> [вкл] Мозаика     1800 мс       [Повторить] [Автопоказ]
  [выкл] Сдвиг     Общая · 1000 мс
  ...                           Длительность: [своя] [1800 мс]
                                Сетка:       [100] [150] [200]
                                Плавность:   [30 % --------]
                                Направление: [Сверху слева v]
                                [Сбросить параметры]

Общий черновик настроек: [Сохранить] [Сбросить изменения]
```

* Каталог — виртуализированный список с названием, переключателем,
  эффективной длительностью и кратким описанием изменённых опций. Группы
  и фильтры — enum; поиск по локализованным названиям и стабильным именам.
* На узком экране сначала список, затем отдельный экран параметров с
  предпросмотром сверху. Общий черновик и выбранная запись не теряются
  при изменении ширины/темы/языка.
* Одна карточка на тип. Контекстные поля показывают только применимые
  настройки: например, у curtain — ось, у diagonal — угол начала раскрытия.
* Длительность: явный выбор «Общая / Своя». Для «Общая» хранится
  `options.durationMs=0`, числовое поле недоступно для редактирования и
  показывает текущее глобальное время, рядом подпись «Общая — 1000 мс».
  Технический ноль не показывается как длительность перехода.
* Для «Своя» доступно поле в миллисекундах, которое принимает только
  положительное целое число (1–3 600 000); общая длительность и каталог
  также используют мс. JSON хранит целое число миллисекунд.
  При первом переключении подставляется глобальная длительность. После
  временного переключения в «Общая» редактор восстанавливает последнее
  корректное своё значение из текущего черновика; оно не хранится вторым
  параметром в конфиге. Reload/сброс очищает это временное значение.
* Переключение в «Общая» явно записывает `0` и снимает ошибку отключённого
  поля своей длительности. Невалидный текст не превращается в `0` сам по себе:
  пока выбран режим «Своя», он блокирует Save и остаётся видимым при возврате
  к этому эффекту. Изменение глобального времени сразу обновляет подписи
  и preview наследующих эффектов; персональные значения сохраняются.
* Поле «Плавность ячеек» показывает процент; подсказка объясняет долю времени
  перехода для затухания одной ячейки. 0% даёт прежнюю бинарную Mosaic.
* Можно просматривать выключенный эффект, не включая его. Выбор строки
  управляет и формой, и preview: второй независимый dropdown эффектов убрать.
* Предпросмотр использует корректные значения черновика без Save. Быстрые
  изменения объединяются перед повторной подготовкой; устаревшие async-ответы
  не заменяют новый просмотр. Невалидное поле помечается; предыдущий корректный
  preview явно подписан, Save блокируется даже после перехода на другую строку.
* «Сбросить параметры» сбрасывает options выбранного типа, включая
  `durationMs=0`, сохраняя включённость. Действия «Включить все», «Выключить
  все», «Вернуть общую длительность всем» действуют на весь каталог с явным
  описанием охвата, независимо от текущего фильтра.
* Один активный preview; анимации в строках каталога не запускать. При скрытии
  страницы/сворачивании preview остановить таймеры и освободить медиа по
  существующим правилам. Смена параметров не создаёт дополнительных плееров
  для частей эффекта и не оставляет старых подготовленных ресурсов.
* Save/Reload, выход с несохранёнными изменениями и применение после
  перезапуска остаются частью общего `ConfigDraft`. Отдельный автосейв и
  применение к работающей рамке не добавлять.
* Названия, подсказки и ошибки — RU/EN ARB и штатный генератор. Проверить
  темы, клавиатуру, увеличенный текст, узкую ширину и длинные переводы.

## 7. Согласованные решения

* Новый `slideshow.effects`: карта с ключами `EffectType`, без `type`
  в `EffectConfig`; одно значение на тип, `enabled`, typed options
  с `durationMs=0` для глобальной длительности и положительным значением
  для своей; глобальная настройка — `defaultDurationMs`.
* Объединения из таблицы, включая Mosaic с `fadeFraction=0` как бинарный
  вариант и группы `slide`/`revealMask`; разные алгоритмы остаются разными типами.
* Пустой или несовместимый набор использует явно описанный служебный Fade;
  это не скрытое включение всего каталога.
* Каталог с поиском/фильтрами, один выбранный эффект, контекстная форма
  и один связанный предпросмотр; существующий общий Save/Reload.
* Реализация в пять этапов с локальными регрессиями; OpenGL A/B исключён
  последующим указанием пользователя.

Согласование завершено. Реализация описана в [руководстве](effect-settings.md).
Аппаратные прогоны не выполняются по указанию пользователя.
