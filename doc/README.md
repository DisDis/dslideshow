## Как поддерживать порядок

Нормативные [правила сопровождения документации](../AGENTS.md#сопровождение-документации)
задают структуру, единственное руководство на тему, жизненный цикл планов,
навигацию и проверки. Новый материал размещайте по назначению:

| Каталог | Что хранится |
| --- | --- |
| `doc/` | Индекс и действующие руководства |
| `doc/plans/` | Незавершённые планы и общая очередь |
| `doc/history/releases/` | Датированные записи подготовки выпусков |
| `doc/history/` | Прочая полезная история решений и проверок |
| `doc/images/` | Используемые иллюстрации и manifest их происхождения |
| `doc/hw_test/` | Отдельные аппаратные эксперименты |
| `benchmarks/reports/` | Исследования стенда и доказательства измерений |

При завершении работы переносите актуальный контракт в руководство, результаты
в отчёт и удаляйте выполненный план после сохранения уникальных сведений.
Перед удалением или переносом исправляйте все ссылки, включая ссылки внутри
самого документа. Документальная правка не требует сборки DEB или запуска
браузера/устройства; проверяются ссылки, команды и итоговый diff.
