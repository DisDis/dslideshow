# config_app

Панель настройки фоторамки. Для сборки нужен Flutter 3.47+ / Dart 3.13+.

[План улучшений и локальные проверки](../doc/config-app-improvements.md):
адаптивный интерфейс, русский/английский языки, светлая/тёмная тема,
живой предпросмотр, черновик настроек, Save/Reload и защита несохранённых
правок, таймауты WebSocket/RPC и обработка разрыва соединения.

В меню **Оформление** выбираются язык и тема панели; по умолчанию используются
системные настройки. Выбор действует в текущей сессии панели и не меняет
конфигурацию фоторамки. На широком окне меню остаётся видимым слева,
на узком открывается кнопкой в заголовке. Визуальные редакторы показывают
предпросмотр рядом с формой либо над ней; его можно свернуть.

При запуске панель сразу показывает вход, если подключение ещё не
авторизовано, либо главную страницу при действующей авторизации.
Маршрут определяется по текущему состоянию подключения, даже если оно
изменилось до появления интерфейса. Автоматического восстановления сессии нет.

[Специальные экраны](../doc/special-screens.md): редактор часов и камер,
предпросмотр, отдельные шрифты времени/даты, день недели, таймаут снимка камеры,
порядок показа и компактное сохранение конфигурации.

## Linux desktop

Из папки `config_app`:

```sh
./build_linux.sh --debug
flutter run -d linux
```

Если после исправления обработчика стек ошибки по-прежнему указывает на старую
строку или выражение, выполните полный Restart отладки (Stop → Start) из
каталога `config_app`. Hot reload сохраняет состояние работающего приложения;
при диагностике важно проверить, что запущен именно текущий checkout.
Для панели, которую отдаёт отдельный web-сервер или фоторамка, изменение
`lib/` не обновляет обслуживаемую сборку: нужно обновить её на этом сервере.

Для release-сборки используйте `./build_linux.sh --release`.
Скрипт проверяет инструменты и GTK, очищает нативный CMake-кэш,
выполняет `flutter pub get` и сборку. Обновление путей GTK также работает
при обычном `flutter build linux` и запуске из VS Code.

Зависимости, причины ошибок `PkgConfig::GTK` и GSettings, способы диагностики
и порядок переноса исправления в другие приложения описаны в
[инструкции по Linux-сборке](../doc/linux-build-troubleshooting.md).

[Новые эффекты и Ken Burns](../doc/new-visuals-2026-10.md): настройка, совместимость,
предпросмотр, тесты и измерения на RaPi5.
