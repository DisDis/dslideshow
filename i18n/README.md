# Локализации

`app_en.arb` задаёт набор сообщений, `app_ru.arb` содержит русский перевод.
Перед удалением ключа проверьте его использование во всём репозитории:
подписи предпросмотра могут также использоваться галереей и управлением рамкой.

Из каталога `i18n/` после изменения ARB:

```sh
flutter gen-l10n
flutter analyze --no-pub
flutter test --no-pub
```

Генератор читает `l10n.yaml` и обновляет `lib/src/generated/`.
Сгенерированные файлы вручную не редактируются. После изменения публичных
ключей проверьте затронутые потребители в `config_app/` и `dslideshow_flutter/`.
